2025-08-06
It is recommended that the Glyphs plugin `Better VF Export` is installed. This plugin with automatically run after each VF export and fix the STAT table in the generated binaries.

2025-07-29
Glyphs contains a long standing bug that malforms the STAT table in variable fonts. The current workaround is the `Read and Write STAT` script in `mekkablue > Post Production`. Run it after export, then edit the parameters in the variable font setting in `Font > Exports`. Then run the script again. And after each export!
